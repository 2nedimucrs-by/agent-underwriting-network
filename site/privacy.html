DATA MINIMIZATION

Privacy

Public evidence can be browsed without an account. Account and product analytics features are optional and are designed to collect only the data needed to provide the requested feature.

Public browsing

The public directory, Trust Cards and comparison pages do not require registration. The site may use privacy-oriented aggregate web analytics when configured.

Accounts

If account features are enabled and you sign in, the service may store your user ID, email address supplied by the authentication provider, GitHub login/avatar when supplied, account creation time, saved agents, alert preferences and maintainer claim records.

GitHub sign-in

The service does not ask for or store your GitHub password. A GitHub maintainer identity claim is separate from evidence about an agent's security, capability or reliability.

Optional product analytics

When first-party product analytics are configured, an optional consent prompt controls collection of product interaction events such as page views, searches, Trust Card views, comparisons and claim starts. The product-event schema does not include a raw IP-address field.

Public-source agent data

Agent profiles are generated from public project metadata and evidence sources. Discovery metadata is not presented as proof of security or capability.

Retention and deletion

Registered users can submit an account deletion request from the account page. Operational evidence may remain when it is about a public software artifact rather than the user's personal account, but personal account associations should be removed when the request is completed.

Outreach

The project policy prohibits bulk personal-email scraping and mass messaging of GitHub stargazers. Outreach is intended to use public professional context and suppression/opt-out controls.

Security or privacy requests

Use the repository's private security reporting channel when available for sensitive reports. Do not post secrets or personal data in public GitHub issues.

Draft operational policy · 2 October 2026. Review with qualified counsel before commercial launch in jurisdictions that require additional disclosures.
