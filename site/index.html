WHAT WE MEASURE

Eight independent evidence dimensions

Safe is not the same as capable. Capable is not the same as authorized. Authorized is not the same as economical.

IdentityWho publishes the agent?
ProvenanceWhich exact source and version?
SecurityWhat tested risks were observed?
PermissionsWhat can it read, write or call?
CapabilityWhich tasks were actually completed?
ReliabilityHow consistently does it succeed?
EconomicsWhat does successful work cost?
FreshnessIs the evidence still current?
