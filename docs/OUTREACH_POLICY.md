# Outreach policy

Growth must preserve the credibility of an independent verification network.

## Allowed

- contact maintainers through public professional channels
- mention a public repository or release that was actually analyzed
- offer a free report or maintainer claim flow
- send a small number of highly contextual messages
- maintain an opt-out and suppression list

## Not allowed

- bulk scraping personal email addresses
- mass messaging GitHub stargazers
- automated issue/comment advertising
- invented security findings
- claiming endorsement before a maintainer explicitly claims a profile
- using private repository data for public lead generation

## Default automation boundary

Lead discovery and message drafting may be automatic.

External sending remains human-approved until explicit policy, rate limits, suppression handling and legal/compliance review are in place.
