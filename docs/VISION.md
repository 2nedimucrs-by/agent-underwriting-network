# Vision

Build the independent evidence layer for an economy in which software agents discover tools, hire other agents and perform real work.

The network should become more useful when more agent frameworks, MCP servers, A2A agents, marketplaces, sandboxes, scanners and payment systems appear.

## North star

Given a version-pinned agent and a proposed task, answer:

**What evidence supports giving this agent this task, with these permissions and limits, right now?**

## What we are not building first

- another general agent framework
- another universal agent sandbox
- another MCP gateway
- another wallet or crypto rail
- a star-rating marketplace
- an opaque single-number trust score

The long-term sequence is:

**Index -> Underwriting API -> Router -> Verified Labor Exchange**
