# Growth loop

## Supply acquisition

Discover public agents -> create discovery-only profile -> run evidence pipeline -> invite maintainer to claim profile -> maintainer reviews evidence -> optional README badge -> badge drives new visitors and scans.

## Buyer acquisition

Detect public implementation intent -> prepare a contextual report about the exact agent/version -> offer the evidence report or private verification -> convert repeated usage into API/monitoring plans.

## Outreach constraints

- Use public/professional contact points.
- Do not scrape private/personal email databases.
- Do not mass-message stargazers.
- Do not imply a maintainer requested or endorsed a profile before they claim it.
- Prefer a small number of high-context messages over bulk outreach.

## Network effect

More frameworks, agents, registries, scanners, sandboxes and marketplaces should increase the number and quality of evidence sources rather than reduce the addressable market.
