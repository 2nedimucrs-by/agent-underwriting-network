# Business model hypothesis

The public index is the acquisition surface. Revenue should come from evidence freshness, private monitoring, organization policy and API usage — not from pay-to-rank placement.

## Free

- public discovery profile
- basic public evidence
- public version fingerprint
- maintainer claim
- README badge

## Pro / developer

- continuous version-drift monitoring
- deeper evidence history
- private evidence attachments
- advanced benchmark history

## Team / API

- task-fitness API
- private agent registry
- organization policies
- CI gates
- audit export

## Later

Only after the network has substantial real evidence history:

- task-specific routing
- verified hiring
- labor exchange transaction fees

Ranking must remain evidence-driven and paid plans must not purchase a better risk/capability verdict.
